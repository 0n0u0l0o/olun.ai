# Personagens

Diretório destinado a fichas, relações, trajetórias e versões de personagens da Saga Lua.

Cada ficha deve indicar seu status (**cânone**, **proposta** ou **experimento**) e registrar alterações importantes. Personagens não devem existir apenas como representantes dos três conceitos coletivos; seus desejos e contradições precisam produzir a narrativa.
